Personal blog of Morwenn (@morwenn on Codeberg and other places). I intend to write about programming and programming-adjacent topics here.
I might eventually publish articles that have little to do with programming if I can't find another relevant places to share them.

Sources for all blog articles can be found on [the corresponding GitHub repository](https://github.com/Morwenn/morwenn.github.io).
* Branch `gh-pages` has the blog and its articles.
* Branch `resources` contains lots of scripts corresponding to the code and images from the blog.

I voluntarily did not license any code or contents present there, because it's possibly a mix of various sources.
Using an overarching license over the repository would might therefore be incorrect and lead to issues.
If you want to reuse contents from that repository, feel free to ask and I might relicense code as needed.

I like to add em-dashes every now and then to keep people on their toes <3
